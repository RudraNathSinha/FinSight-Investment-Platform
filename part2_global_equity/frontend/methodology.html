Methodology

How FinSight collects, merges, and presents equity analytics

1. Purpose

FinSight is an educational analytics workspace. It helps students, new joiners, data analysts, and finance professionals explore global equity listings and generate structured research-style packs from public free data sources. It is not SEBI-registered research, a portfolio recommendation service, or personalised investment advice.

2. Universe coverage

The listing universe is stored in a local database compiled from public exchange and directory sources. Country packs under data/country_packs/ extend coverage for markets where live feeds are thin. Search, sector, industry, and peer tools read from this universe.

3. Data sources and preference order

For a selected symbol and exchange, FinSight requests data in parallel and merges fields using a fixed preference order:

  1. stockanalysis.com scrape — primary for statements and profile pages when reachable
  2. yfinance — prices, key statistics, history, and statements when the ticker resolves
  3. Free public APIs — supplementary quotes and metadata
  4. Multi-source bundle merge — field-level fill of gaps across the above
  5. Rule-based synthesizer — narrative structure (SWOT-style points, risk register, recommendation framing) derived from available numbers; not a generative market forecast model
  6. Local country packs — offline JSON last resort only when live sources return no usable data

When a field is missing upstream, a lower-preference source may fill it. Blank cells mean no free feed provided the value.

4. Statement construction and YoY growth

Income statement, balance sheet, and cash-flow tables are normalised into period columns. Year-over-year (YoY) rows are computed as percentage change versus the prior column when both values are numeric and the base is non-zero. Positive YoY is shown in green; negative YoY in red in the web app and in print/PDF output.

Restatements, discontinued operations, and one-off items may not be flagged by free feeds. Always reconcile material lines with primary exchange filings.

5. Ratios, insights, and recommendation

Ratios use disclosed or computed values from the merged snapshot. Investor insights are rule-based interpretations of definition plus observed level (for example valuation multiples, leverage, liquidity). They are educational commentary, not target prices.

The Buy / Hold / Sell stance in the equity report is an automated score synthesising growth, profitability, cash flow, leverage, valuation, and qualitative SWOT-style factors from the same pack. Score thresholds are heuristic. Classroom mode reduces emphasis on recommendation language for teaching use.

6. Equity research report structure

Generated reports follow a multi-chapter template: cover, index, how-to-read, methodology snapshot, company profile, statements with YoY, ratios, SWOT, PESTLE, risks, dividends (if available), price trajectory, synthesis, recommendation with detailed rationale, glossary, and thank-you page. Template version is shown in the page footer (currently v1.2).

7. Caching and refresh

Merged report payloads may be cached briefly in memory to speed repeat views. Rebuilding country packs via the admin rebuild endpoint clears the report cache. Users should hard-refresh the browser after major server updates.

8. Limitations

  • Free data can be incomplete, delayed, or inconsistent across secondary listings.
  • Secondary tickers may not be the issuer’s primary listing.
  • Models and scores are illustrative; they do not incorporate proprietary order-book, alternative data, or human analyst overrides.
  • Country ranking module uses a separate indicator methodology documented in that module’s data notes.

9. Good practice for users

  • Verify material figures in annual reports, interim filings, and exchange announcements.
  • Compare ratios within the same industry and accounting regime.
  • Treat recommendation labels as discussion prompts, not instructions to trade.
  • Consult a licensed adviser for personalised decisions.
