How FinSight works

Plain-language methodology for long-term investors. This is an educational workspace — not formal research advice.

1. Universe & hierarchy

Stocks are organised Sector → Industry → Stock using offline ranking workbooks built from multi-criteria decision methods (MCDM). Live quotes and financial statements are fetched separately via market data (yfinance through the FinSight Flask API).

2. Ranking methods (MCDM ensemble)

Industry and stock ranks combine several standard MCDM techniques (for example SAW, TOPSIS, VIKOR, GRA, WASPAS, COPRAS, and related scoring). In simple terms:

  • Each method scores names on the same set of quantitative factors (quality, growth, risk-style inputs as available in the ranking files).
  • Scores are normalised so methods can be compared.
  • An ensemble / blended rank summarises agreement across methods — useful for screening, not as a buy/sell call.

Ranks can change when inputs or peer sets change. Always open the full stock analysis before acting.

3. Financial statements & ratios

Income statement, balance sheet, cash flow and ratio panels use reported annual/quarterly history from the live feed. Growth rates are year-over-year where both periods exist. Missing lines are common for some tickers — FinSight shows an explicit empty state rather than inventing numbers.

4. Valuation (DCF-style)

The valuation module builds an illustrative discounted free-cash-flow path:

  • Base revenue / FCF from the latest available annuals.
  • Near-term growth faded toward a long-run terminal growth rate.
  • Discount rate anchored to published cost-of-capital context (Damodaran-linked illustrative rate), not a company-specific CAPM audit.
  • Terminal value via Gordon growth; equity value = enterprise PV − net debt.

Asset and market cross-checks (book, PE / EV multiples) are shown for triangulation. Results are scenario illustrations.

5. Financial model pack

The three-statement view links historical income, balance sheet and cash flow. The DCF block mirrors valuation. The LBO block is a teaching sketch (entry EV, debt schedule, exit multiple, MOIC/IRR) — not a live deal model.

6. Reports

Equity Research, Valuation and Financial Model reports assemble the same panels into printable HTML/PDF. They inherit live-data limits and model assumptions. Always verify against primary filings.

Intended use

FinSight helps long-term investors structure the universe, read fundamentals, and prepare questions before speaking with a broker or advisor. It does not replace regulated advice.
